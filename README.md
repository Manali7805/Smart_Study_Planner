# Smart_Study_Planner
 An intelligent AI-powered study planning platform that helps students organize study tasks, manage exam preparation, track learning progress, and generate personalized study plans.

# Overview

 Smart Study Planner is a web-based academic planning application designed to help students manage their studies in a smarter and more organized way.

The application allows students to create study tasks, set priorities and dates, track completion, monitor weekly progress, and receive AI-powered study recommendations.

The long-term goal of the project is to develop an intelligent academic assistant that can understand a student's syllabus, exam dates, available study hours, topic difficulty, and learning progress to generate a personalized and adaptive study plan.

---

# Problem Statement

Students often face difficulties such as:

-  Managing multiple subjects
-  Planning available study hours
-  Preparing for exams on time
-  Missing planned study sessions
-  Forgetting previously studied topics
-  Understanding their actual progress
-  Deciding what to study next

Traditional to-do lists only store tasks. They do not intelligently prioritize topics or adapt the study schedule according to the student's academic situation.

 Smart Study Planner aims to solve this problem by combining task management, progress tracking, scheduling, and AI-based study assistance in one platform.

#  Features

# 1. Smart Dashboard

The dashboard provides a centralized view of the student's learning activity.

It includes:

-  Study Hours
-  Learning Progress
-  Today's Tasks
-  AI Study Recommendations
-  Today's Study Schedule
-  Study Streak
-  Weekly Progress
-  Achievements

The dashboard is designed using a **Deep Space AI** theme with blue, indigo, and purple accents.

---

# 2. Study Task Management

Students can create and manage individual study tasks.

Each task contains:

-  Subject
-  Topic
-  Study Date
-  Priority
-  Completion Status

Students can:

-  Add tasks
-  Mark tasks as completed
-  Delete tasks
-  View pending tasks
-  Track completion progress

Example:


Subject: Operating Systems
Topic: CPU Scheduling
Date: 2026-08-10
Priority: High
Status: Pending
